    How it works
    
          
    A paste is intercepted, rebuilt from meaning rather than markup, and re-rendered for the destination.
    
        
    
        
      
          
    1. CopyThe clipboard holds text/plain and often text/html.
      2. 
          
    2. Detect contentHTML, Markdown, PDF-wrapped text, spreadsheet rows or plain prose.
      3. 
          
    3. NormalizeParse into a small document model: paragraphs, headings, lists, links, emphasis.
      4. 
          
    4. Detect destinationGmail, Slack, Notion, Google Docs, rich editor or plain field.
      5. 
          
    5. FormatEach destination adapter renders what that app supports, and nothing it doesn't.
      6. 
          
    6. SanitizeAllowlisted tags, escaped text, vetted URLs. Source styles never pass through.
      7. 
          
    7. PasteHanded to the editor's own paste handler, or inserted directly. Any failure falls back to a normal paste.
      8. 
        
    
        
    
          
    Honest limits
    
          
      
            
    • Google Docs draws its editor on a canvas, so Magic Paste hands the cleaned content to Docs' own paste handler instead of inserting it. If Docs ever declines it, you get a normal paste; Clean clipboard in the popup is the backup.
      • 
            
    • Images and files pass through untouched. Turning screenshots of text into text would need OCR.
      • 
            
    • Chrome pages (chrome://, the Web Store, the built-in PDF viewer) don't allow extensions to run.
      • 
            
    • Custom editors are reached through their standard paste handling; an editor that ignores it gets a normal paste.
      •
